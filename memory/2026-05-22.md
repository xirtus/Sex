## Lessons Learned
- Always run `bash -n` to test syntax correctness of shell script gates.
- Duplicate blocks in shell scripts can easily lead to syntax issues (like nested or unexpected `fi` statements) and incorrect logic evaluation. Checking exact line numbers with `view_file` helps identify duplicate patterns cleanly.
- Tracing early discovery checks (like `[kernel.pci.nvme.absent]`) against host execution files (like `run_daily_driver_proof.sh`) cleanly separates virtual device absence from actual driver queue implementation bugs.
