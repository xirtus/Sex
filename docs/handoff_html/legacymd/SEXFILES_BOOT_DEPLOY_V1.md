## What Was Intentionally NOT Done

1. **No SLOT_STORAGE grant to any client** — silk-shell, Quil, Linen cannot
   call sexfiles yet. SexFiles runs but no PD can reach it via PDX call.
2. **No sexfiles self-cap** — not needed. sexfiles listens on slot 0.
3. **No sex-pdx ABI changes** — SLOT_STORAGE=1 already existed.
4. **No DiskFS/TmpFS changes** — remain stubs returning ERR_NOT_FOUND.
5. **No content-addressing, BLAKE3, journal, snapshots** — later SexFiles on-disk format design.
6. **No RamFS proof activation in ISO** — SEXFILES_RAMFS_PROOF not set at
   compile time. Proofs validated via `cargo check` only.
7. **No runtime gate PD count change** — sexfiles check is a separate gate,
   not incorporated into SPAWN_GATE. Gate is skipped unless
   `SEXOS_SEXFILES_BOOT_PROOF=1`.
